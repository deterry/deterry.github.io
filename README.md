# Personal site
 
Static site: `index.html`, `publications.html`, `style.css`, plus `cv.pdf` (add your own).
 
## Publish on GitHub Pages
1. Create a public repo named exactly `<your-github-username>.github.io`
2. Add these files to the repo root and push
3. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`
4. After a minute the site is live at `https://<your-github-username>.github.io`
## Before publishing
- Replace the LinkedIn URL in index.html
- Fill in the author list in publications.html
- Add cv.pdf to the repo root
- Uncomment the Scholar link if you have a Google Scholar profile
